# How to Write a New Blog Post

Writing a new blog post is easy! Here's how you do it:

## Step 1: Create a New File

Create a new file in the `content/posts/` folder. Name it something like `my-post-title.md`

## Step 2: Add Front Matter

At the top of your file, add this:

```
---
title: "Your Post Title"
date: 2025-11-18
draft: false
tags: ["tag1", "tag2"]
---
```

## Step 3: Write Your Content

Below the front matter (the part between the `---`), write your blog post using simple text. You can use:

- **Bold text** by surrounding words with `**double asterisks**`
- *Italic text* by using `*single asterisks*`
- Create lists with dashes `-` like this list
- Add headings with `#` symbols (more `#` = smaller heading)

## Step 4: Save and Preview

Save your file and your new post will appear on your blog!

That's it - you're now a blogger!
